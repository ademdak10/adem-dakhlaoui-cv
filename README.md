# Adem Dakhlaoui — CV website

## Preview locally

Keep `index.html` and `smart-pet-care-logo.png` in the same folder, then open `index.html` in a web browser. The site is static and needs no build step or dependencies.

## Publish with GitHub Pages

1. Create a GitHub repository for the website.
2. Upload `index.html`, `smart-pet-care-logo.png`, and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, it will show the website URL in the Pages settings.

Review the public profile details before sharing the site.
