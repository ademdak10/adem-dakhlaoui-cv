# Adem Dakhlaoui — CV website

## Preview locally

Open `index.html` in a web browser. The site is a static page and does not need a build step or dependencies.

## Publish with GitHub Pages

1. Create a GitHub repository for the website.
2. Upload `index.html` and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, it will show the website URL in the Pages settings.

Before publishing, replace the contact placeholder with an email or public profile link if you want visitors to contact you. Review all personal information first.
